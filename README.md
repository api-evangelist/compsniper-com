CompSniper provides a unified API that aggregates completed eBay sales data along with listings from TCGplayer, PSA, Grailed, Poshmark, Mercari, and Depop. Developers can retrieve up to 240 sold listings per request, either raw or AI‑cleaned, enabling price analysis, market research, and valuation of collectibles. The service offers a free tier of 100 requests without requiring a credit card, and paid plans for higher volume.

**Areas:** Company · API · Marketplace · E-commerce · Data · Collectibles
